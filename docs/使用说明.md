# dream · 使用说明

一个装在你手机里的独立聊天 App（桌面图标显示为 **dream**）。她直连 DeepSeek 云端说话，人格设定**逐字取自
《设计方案》2.1 节**，所有聊天记录、总结、记忆**只存在这台手机本地**。

- 系统要求：**Android 8.0（API 26）及以上**（按 Android 16 / targetSdk 36 编译）
- 体积：APK 约 14 MB，装完约 30 MB，**不含任何模型文件**
- 构建：**完全在本机完成**，不依赖云服务器、不依赖电脑、不需要 root

---

## 一、安装与首次配置

### 1. 安装

在 `dsh-shared/apks/` 里找到 `dreamgirl-v0.10.0-release.apk`，点它 → 「继续安装」。
覆盖安装不会丢数据（数据库在 App 私有目录，升级保留）。

### 2. 填 API Key（必须）

1. 打开 App → 底部「**设置**」
2. 「DeepSeek API Key」粘贴你的 key（`sk-…`）→ **保存**
3. 点「**测试连接**」，看到「✓ 连接正常」就通了

Key 存在 Android Keystore 加密的容器里（AES256-GCM），**不会写进 APK、不会上传到任何地方**。
随时可以点「删除」换掉。

### 3. 让她能主动找你（可选，但这是她的灵魂之一）

1. 「设置」→ 打开「**允许读取使用时长**」
2. 点「去授权『使用情况访问』」→ 在系统页面里找到 **dream少女** → 打开开关
3. 回到「设置」→ 打开「**让她主动来找你**」
4. 点「加进电池白名单（防被杀）」→ 允许

做完这四步，她才会在你**熬夜、连续盯屏、好久没说话**的时候自己开口。
不授权也能正常聊天，只是她不会主动。「今天」页面顶部的状态卡会明确告诉你
现在是 **◉ 正在观察** 还是 **○ 未在观察**。

## 一点九、改名字、改人格

**改名字**：设置 → 打开人格设定 → 最上面「名字（界面上怎么叫她）」。
默认是 **dream**。改这里**只影响界面标题**，不会动人设原文。

**改她的语气长度**：设置 → 「单条最长 N 字」。嫌她啰嗦就往下拧，觉得太干就往上拧。
超过这个长度会在句子边界截断（不会截半句）。

**看她实际收到什么**：设置 → 「查看提示词」。那里能看到模型真正拿到的那段固定前缀
（人设原文 + few-shot + 格式要求），以及每次请求还会追加什么。觉得她不像时先看这里。

**改人格**：同一页下面那七段（形象 / 性格 / 见地 / 信仰 / 说话方式 / 行为原则 /
名字原文）**全部可改**，改完点「保存」。想还原就点「恢复方案原文」，
一键回到《设计方案》2.1 节的逐字原文。

页面顶部有个徽章会明确告诉你现在是 **✓ 与方案 2.1 节逐字一致** 还是
**✎ 已被你改过** —— 改了哪里、有没有动过原文，一眼可见。

## 二、界面

### 聊天页（首页）

参照微信的「会话列表」：**一行一个"好友"，每个"好友"是她的一天**。

| 位置 | 内容 |
|---|---|
| 顶部 | 居中标题 |
| 每行左侧 | 她的头像（蓝鲸） |
| 每行标题 | 那天（今天 / 昨天 / 前天 / 10月8日…） |
| 每行副标题 | 最后一句说了什么；她主动找过你会特别标出 |
| 每行右侧 | 最后说话的时间 |
| 底部 | 4 个标签：聊天 / 记忆 / 今天 / 设置 |

点任意一行 → 进那天的聊天记录。

### 对话页

参照微信的对话界面：

- 她在左、你在右，各有头像；气泡带小尖角（她的白/深灰，你的微信绿）
- 时间戳居中，**间隔超过 5 分钟才显示一条**
- （动作和神态）用灰色斜体显示，和说话内容分开
- 她打字时内容会实时流出来，列表自动跟着贴到底部
  （只有你本来就在底部时才跟随，不会抢走你往上翻的位置）
- 深浅色**跟随系统**（和微信一致）

### 记忆页

她的长期记忆。每天一条总结，分三层：

| 层 | 内容 | 用途 |
|---|---|---|
| L1 一句话 | 这天的主线 | 列表展示 |
| L2 要点 | 发生了什么 / 你的状态 / 重要决定 / **她答应过的事** | 进 prompt 的主力 |
| L3 细节 | 值得原样记住的话、偏好、承诺、情绪事件 | 日后"她突然提起"用 |

- 点开每条可以看到 L2 / L3
- 下面的「记忆条目」**可以改、可以删**
- 如果某天出现敏感信息（密码、银行卡、身份证号），她会**跳过不记**，
  并在那条总结里标注「**已跳过 N 条敏感内容**」—— 只标数量，不标内容

### 今天页

用机日报：今天亮屏多久、当前连续用了多久、哪个 App 最久、和她说了几句、
最后一次熄屏时间。顶部有常驻的「正在观察」状态。

### 设置页

Key、模型、温度、回复长度、称呼、感知开关、人格设定入口。

## 三、她是怎么"像她"的

四件事共同起作用：

1. **人设原文**放在 prompt 最前面，且**永不改动** —— 这同时命中 DeepSeek 的上下文缓存，
   长期下来输入侧费用能降一个数量级。
2. **Few-shot 示范**：11 个正例 + 3 个反例，把"傲娇但真在乎""先问事实再分析再给最小一步"
   落到具体对话上。描述 + 正例 + 反例，比只写形容词管用得多。
3. **温度**默认 1.0。觉得她太干就往 1.2–1.4 调（设置页有滑块）。
4. **后处理**：一旦出现"作为一个人工智能""综上所述"这类跳出角色或背课文的痕迹，
   会自动让她重说一遍；超过 400 字的小作文会在句子边界截断。

另外，设置里有个「**遇到难题时切到推理模型**」（默认关）。开启后，只有你说
「怎么办 / 该不该 / 帮我分析」这类真正在纠结的话，才会切到 `deepseek-reasoner`；
日常闲聊刻意留在 `deepseek-chat` —— reasoner 更慢、更爱讲道理，用多了反而不像她。

## 四、记忆与总结是**她自己做**的

你不需要点任何按钮。

- **按天分会话**：以本地时间 **04:00** 为界。你凌晨 2 点说的话算前一天 ——
  符合她"熬夜"的语境。第二天第一次和她说话会自动开新会话。
- **新的一天开始时，她自动总结前一天**：打开 App 时会在后台补上，
  前台服务每半小时查一次，后台任务兜底。
  漏掉的会补，**但不会去总结"今天"** —— 今天还没过完。
- **详略判定**：详记你的偏好、明确的计划或承诺、情绪事件、重大决定、她答应过的事；
  寒暄压成一行甚至不记；敏感信息直接跳过；没内容就空着，不为了填满而编。
- **长对话**先分段做小摘要（map）再合并（reduce）；一天只跑一次。
  对话很短时**跳过 map 那一步**，省一次调用。
- **检索**：你发一句话 → 关键词匹配 + 时间衰减 → 命中才拼进 prompt。
  没命中就不硬塞，避免"她莫名其妙提旧事"。
- **体积控制**：超过 90 天的日总结会压缩成月记。
- 全部本地。总结只存在手机 Room 数据库里。

## 五、她怎么知道你在熬夜

感知层（默认关闭，需要你手动开）：

- 只读系统的「使用情况访问」权限，拿到亮屏/熄屏时间线和你当前在用的 App
- **原始日志永远不离开手机**。进模型的只有本地拼好的一句话，
  比如「23:20 还在打游戏，已连打 95 分钟」
- 触发规则：深夜未睡 / 熬夜 / 连续游戏 / 长时间盯屏 / 好久没联系 / 早上刚醒
- 每条规则有冷却时间；**刚聊完 20 分钟内不会插嘴**（深夜除外）
- 通知感知、读屏是 v3 的功能，**默认关闭，这一版没有打开**

## 六、断网 / Key 失效会怎样

不会崩溃，会给你能看懂的话，并且气泡上方出现「重发」按钮：

| 情况 | 提示 |
|---|---|
| 没填 Key | 还没配置 DeepSeek API Key，去「设置」里填一个 |
| Key 失效 | API Key 无效或已失效 |
| 余额不足 | DeepSeek 账户余额不足 |
| 请求过频 | 请求太频繁了，歇一下再试 |
| 服务器 5xx | DeepSeek 服务器出问题了（HTTP 5xx） |
| 断网 / DNS | 连不上网，或者 DNS 有问题 |
| 超时 | 等太久了，网络好像卡住了 |

网络抖动会自动重试 2 次（1.2 秒、2.4 秒退避）；
**Key 错、余额不足不会重试**（重试也没用）。

## 七、费用

用你自己的 DeepSeek 账户，按官方价目表计费。参考量级：一天 100 句大约
十几到几十元/月，人设前缀命中缓存后更低。

设置页把 `max_tokens` 限制在 300 左右，既像她（"不写小作文"）又省钱。
记忆抽取和日总结用的是同一个模型、低温度、小 max_tokens。

## 八、隐私

- 原始使用日志**永远不离开手机**
- 通知感知、读屏默认关
- 「今天」页有常驻的「正在观察」指示，一眼能看出她到底有没有在读你的作息
- 敏感信息识别到就不记，并在 UI 上标注跳过了几条
- 数据库不进云备份（`data_extraction_rules.xml` 已排除全部域名）
- API Key 存在 Keystore 加密容器里

## 九、后台常驻

MIUI / HyperOS 会杀后台。App 用了两重保险：

1. **前台服务**：挂一个低调的常驻通知，让系统知道"她在"。
   用的是 `specialUse` 类型 —— Android 15+ 对 `dataSync` 有每 24 小时 6 小时的上限，
   用 `dataSync` 会被系统掐掉。
2. **WorkManager**：15 分钟一次的兜底检查。

即便如此也做不到 100%。**务必把她加进电池白名单**（设置页有入口），
并在系统设置里把「省电策略」设为「无限制」。
另外实测 MIUI 在**覆盖安装后不会自动拉起**，要手动打开一次。

## 十、从源码构建（完全本地）

```bash
/opt/dream/build.sh assembleRelease     # 出正式包
/opt/dream/build.sh assembleDebug       # 出调试包
/opt/dream/build.sh testDebugUnitTest   # 跑 161 个单元测试
```

产物：`app/build/outputs/apk/release/app-release.apk`

**本机特殊之处**（详见 `RULES.md`）：Google 只发布 x86_64 的 Linux `aapt2`，
而本机是 aarch64。项目用 `qemu-x86_64-static` + x86_64 glibc sysroot 运行官方 aapt2，
通过 `gradle.properties` 的 `android.aapt2FromMavenOverride` 挂上去。
删掉那一行构建会直接失败。

**人格原文防线**：`tools/verify_persona.py` 已挂到 Gradle `preBuild`。
任何人改了 `PersonaVerbatim.kt` 里的人格原文，构建会**直接失败**。

## 十一、常见问题

**Q：她为什么不主动找我？**
A：三件事都要做到：① 设置里打开「允许读取使用时长」并授权；
② 打开「让她主动来找你」；③ 加进电池白名单。「今天」页顶部显示
「◉ 正在观察」才说明真的生效了。

**Q：为什么记忆页是空的？**
A：总结是**新的一天开始时**才做的。今天聊完，明天打开 App 才会看到今天的总结。
如果之前有漏掉的，她打开 App 时会自动补上。

**Q：聊天记录会丢吗？**
A：不会。都在本机 Room 数据库里，覆盖安装也不清空（v1→v2 用的是真迁移）。

**Q：能改她的人设吗？**
A：可以。设置 → 打开人格设定。出厂状态就是《设计方案》2.1 节的原文，
一字未改；你改过之后会显示「✎ 已被你改过」，也可以一键「恢复方案原文」。
